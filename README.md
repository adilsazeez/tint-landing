# Tint landing

Marketing one-pager for **Tint** (agent-curated Home Screen glances).

Static site only — HTML/CSS at repo root. Hosted on **Vercel**. The API/MCP live in [`adilsazeez/tint`](https://github.com/adilsazeez/tint) on Render.

## Local preview

```bash
python3 -m http.server 8765
```

Open http://127.0.0.1:8765/

## Deploy

Link this repo in Vercel with Root Directory `.` (site root). Production branch: `main`.
